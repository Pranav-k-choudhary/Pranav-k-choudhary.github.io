The Amazon Clone is a frontend web development project built using HTML and CSS. The primary goal of this project is to practice and improve skills in web page structure, layout design, and responsive styling by recreating the interface of a real-world e-commerce platform like Amazon. Currently, the project focuses on designing the visual homepage, which includes a header section with a logo, search bar, and navigation links, a banner section, a product cards layout, and a footer. The design aims to provide a clean, user-friendly experience while closely resembling the original website. This project is still under development and is being improved step by step. At present, it features an Amazon-like homepage layout along with a responsive design implemented using CSS. In the future, the project will be enhanced by adding JavaScript for interactivity, implementing features like cart and login user interface, creating product detail pages, and improving overall responsiveness and animations. This project is currently a work in progress, and more updates will be added in future commits.

This is a simple and responsive calculator built using HTML, CSS, and JavaScript. It is designed with a clean and modern user interface, making it easy to perform basic arithmetic operations. The calculator supports operations like addition, subtraction, multiplication, division, and modulus. It displays user input in real-time and includes a clear (C) button to reset calculations quickly.The user interface is interactive, with smooth button click effects, hover states, and a simple layout that enhances usability. The design is fully responsive, The functionality is implemented using JavaScript, where button clicks are handled through event listeners. The input is stored as a string and evaluated using the eval() function, with the result displayed instantly on the screen. Technologies Used: HTML, CSS (Grid, Flexbox, Media Queries), and JavaScript (DOM Manipulation and Event Handling).

This is a simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript, where the user plays against the computer with real-time result display, dynamic score tracking, and a clean, modern, and fully responsive interface that works smoothly across desktop, tablet, and mobile devices. The player selects Rock, Paper, or Scissors while the computer generates a random choice, the winner is decided based on standard circular rules (Rock beats Scissors, Scissors beat Paper, and Paper beats Rock), scores are updated dynamically after each round, draws occur when both choices are the same, and the first player to reach 10 points wins the game, after which it automatically resets for a new match.

This is a simple and interactive Tic Tac Toe game developed using HTML, CSS, and JavaScript, designed with a clean and responsive interface where two players, Player O and Player X, play turn by turn starting with Player O, placing their marks on empty cells while the game automatically checks for a winner after each move based on horizontal, vertical, or diagonal combinations, and declares the result accordingly or allows a reset if all cells are filled without a winner; it also includes features like New Game for starting a fresh match, Reset Game to clear the current board, and an Undo button to revert the last move, making the gameplay smooth and user-friendly.

This is a simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript that allows users to convert currencies in real time using live exchange rates fetched from an API, supporting multiple international currencies with dynamic country flags that update based on selection, while providing a fast, clean, and mobile-friendly user interface; the user enters an amount, selects the “From” and “To” currencies, and the app uses Fetch API with async/await to retrieve the latest exchange rates from the Exchange Rate API and displays the converted result instantly, along with country flags from the Flags API, utilizing core concepts like DOM manipulation, event handling, and dynamic UI updates to ensure a smooth and interactive experience.

Built a responsive and user-friendly Expense Tracker web application using React.js and Vite to help users manage daily expenses efficiently. The application allows users to add and delete expenses, automatically calculates total expenses, and stores all data in browser localStorage for persistent access even after page refresh. The project follows a component-based architecture where the App component manages state using useState, stores data using useEffect, and passes data through props to child components like ExpenseForm, ExpenseList, and ExpenseItem. Expense deletion is handled using the filter() method, while total expense calculation is performed using reduce(). Additionally, the project integrates Auth0 authentication for secure login and logout functionality, including session persistence and support for social login. The application is fully responsive and optimized for both mobile and desktop devices.
