## Personal Portfolio Website

This is a responsive Personal Portfolio Website built using HTML, CSS, Bootstrap, and JavaScript.
It showcases my profile, education, skills, projects, certifications, and contact details in a modern and user-friendly interface.

## Features
 -> Responsive design(mobile, tablet, desktop)
 -> Interactive Bootstrap Navbar
 -> Hero section with introduction
 -> About Me section
 -> Resume preview & download
 -> Education details with styled tables
 -> Skills section
 -> Certifications with modal preview
 -> Projects section with:
       - Accordion layout
       - Image sliders(carousel)
       - Project descriptions
 -> Contact form(Formspree integration)
 -> Social media links(LinkedIn, GitHub, Instagram)
 -> Coding Platform(LeetCode, Gfg)

 ## Technologies Used
  -> HTML – Structure of the website
  -> CSS – Styling and layout
  -> Bootstrap  – Responsive design & components
  -> JavaScript – Interactivity and form handling

## Pages Description
 * Home Page:
    - Navigation bar
    - Hero section with introduction
    - About Me section
    - Footer with contact & social links
 * Resume Page:
    - Resume preview(click to scale)
    - Download resume option
 * Education Page:
    - Academic details in table format
    - Styled UI with hover effects
 * Skills Page:
    - Technical and soft skills listed in table format
 * Certifications Page:
    - Certificates displayed using cards
    - Modal popup for full view
 * Projects Page:
    - GitHub profile link
    - Accordion-based project showcase
    - Image sliders & videos
 * Contact Page:
    - Contact form using Formspree
    - User can send message
    - Redirect on successful submission
